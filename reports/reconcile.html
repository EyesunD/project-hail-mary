Methodology

Architecture (signed off 2026-05-31): reconcile.html answers ONE question — "does our model match the app?". App values (start AND end) come from the user-maintained PortfolioValueSGD sheet in holding.xlsx; our model is the validation column.

  • App (start) / App (end): both sourced from the PortfolioValueSGD sheet — start = snapshot closest to the statement date; end = snapshot closest to today. These are the "what really happened" numbers, untouched by our reconstruction.
  • Δ Perf: app_end - app_start - deposits. Pure deposit-adjusted performance per sleeve, in SGD.
  • Weight source: target % (piecewise) — uses the target snapshot effective at each sub-period within (stmt_date, end_date]. When you change a target mid-period (e.g. removed Crypto from GI on May 26), the period is sliced and each sub-period uses its own targets, with cumulative compounding across segments. Falls back to stmt-date actual weights for segments where target coverage is incomplete.
  • Value movement: buy-and-hold per holding within each sub-period — seg_return = Σ_h w_seg[h] × (p_end / p_start). The portfolio cum return is the product across segments.
  • FX pinned to your PDF stmt's rate at start (so stmt SGD matches the app exactly); mark-to-market Yahoo daily USDSGD for every other date.
  • Cash / MMF forward-accrual: where Yahoo NAV for a low-vol holding (Cash, Money Market, Treasury 0-3M) lags by 1-2 days, we project missing days at the holding's own realised yield. Marked in drill-down with * and (+Nd).
  • Synthetic cash dropped (M5, 2026-05-31): CASH_USD / CASH_SGD placeholders now return zero. Real cash positions use real Yahoo tickers (LionGlobal SGD MMF + Enhanced Liquidity, OCBC SGD MMF, BB3M.L) that flow through the buy-and-hold path with forward-accrual.
  • Deposits summed from holding.xlsx's Deposits sheet (rows with date > stmt date). Subtracted from Δ Perf and added into our-model+deposits for the gap calculation.
  • Drill-down vs sleeve total: per-holding values in the drill-down use simple point-to-point (stmt → today) ratios. The sleeve Total there sums those — for sleeves that DID change targets mid-period this may differ from "Our Model" in the table above by the rebalancing effect. Treat the table's "Our Model" as the authoritative piecewise number; the drill-down is the per-holding break-out.
  • Status badges: exact (<0.05%), ok (<0.3%), noise (<1%), ⚠ investigate (≥1%).
